# RichChords updates

Public version manifest and changelog for **RichChords**, the chord-glaze
plug-in by ACAS Tools.

The RichChords plug-in fetches `update-manifest.json` from this repository
when — and only when — a user clicks **Check Updates** inside the plug-in.
The request carries no account, project, preset, or device information, and
the plug-in never downloads or executes files itself; it only opens the
release download page in the user's browser.
